# Poke Trainer (내 트레이너)

플레이어마다 NPC 트레이너 한 명을 키우는 모드입니다. 내 포켓몬을 맡기면 트레이너가 AI로 알아서 배틀하며 성장합니다. 관동 지방을 모두 클리어한 사람만 쓸 수 있습니다.

- 버전: 1.6.0
- Minecraft 1.21.1 / Fabric
- 필요한 모드: Cobblemon, Radical Cobblemon Trainers (rctmod, rctapi), CobbleDollars, Fabric API (Mega Showdown이 있으면 Z기술/다이맥스도 사용)
- 설치: 서버에만 넣으면 됩니다. 접속하는 사람(클라이언트)은 이 모드가 없어도 됩니다.

## 기능

- 트레이너 로드: 관동부터 팔데아까지 관장/사천왕/챔피언 117단계에 차례로 도전
- 성장: 이기면 쓰러뜨린 상대에 따라 경험치를 얻고, 정해 둔 능력치의 노력치가 오름 (레벨 상한까지)
- 맡길 때 레벨이 높으면 자동으로 레벨 보정
- AI: 메가진화, Z기술, 다이맥스, 테라스탈을 사용하고, 교체를 남발하지 않음
- 친선전: 다른 플레이어의 트레이너와 배틀
- 관전: 배틀 중인 트레이너를 우클릭
- 내 체육관: 트레이너를 관장으로 앉혀 두면 다른 플레이어가 직접 도전 (Lv.50 6:6, 도전료/상금/보상 아이템)

## 사용법

| 명령어 | 설명 |
|---|---|
| `/trainer (/트레이너)` | 트레이너 화면 (만들기, 포켓몬 맡기기/돌려받기, 순서 바꾸기, 도전, 친선전, 체육관) |
| `/trainer create <이름> (/트레이너 생성)` | 트레이너 만들기 (rename / 이름: 이름 바꾸기) |
| `/trainer give | take | lead (맡기기 / 돌려받기 / 선두)` | 포켓몬 맡기기 / 돌려받기 / 선봉 정하기 |
| `/trainer challenge (/트레이너 도전)` | 트레이너 로드 다음 상대에게 도전 |
| `/trainer friendly <플레이어> (/트레이너 친선)` | 친선전 신청 (accept / decline = 수락 / 거절) |
| `/gym (/체육관)` | 체육관 목록, 도전 |
| `/gym mine (/체육관 내체육관)` | 내 체육관 관리 (타입, 도전료, 상금, 금고, 보상 아이템) |
| `/trainer debug ...` | (OP) 테스트 배틀 |
| `/trainer debuggym ...` | (OP) 체육관 테스트 |

(OP) 표시가 있는 명령어는 서버 관리자(OP)만 쓸 수 있습니다.

## 빌드

```bash
./gradlew build
```

`build/libs/` 에 만들어진 jar 파일을 서버의 `mods` 폴더에 넣습니다.
